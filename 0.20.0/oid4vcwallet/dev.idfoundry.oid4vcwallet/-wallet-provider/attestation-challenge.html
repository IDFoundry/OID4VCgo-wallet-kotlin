attestationChallenge

open suspend fun attestationChallenge(purpose: KeyPurpose): ByteArray?(source)

A challenge for the key attestation of the next key the wallet makes for purpose — fresh, from the Wallet Provider's backend, which remembers it — or null for none. The wallet gives it to KeyStore.createKey, so AndroidKeystoreKeyStore has Android Keystore attest the key over it (setAttestationChallenge), and the key's chain then reaches walletAttestation or keyAttestation in its KeyEvidence. Return one for KeyPurpose.HOLDER (Key Attestation) and KeyPurpose.INSTANCE (Wallet Attestation); KeyPurpose.DPOP keys aren't attested to anyone. At most 128 bytes. Called on Go's thread, which waits, once per key: a batch asks once per copy. An IOException is reported as a network failure, as the attestations' are. The default gives none, and keys carry no attestation chain.
