WalletException

class WalletException : Exception(source)

An error from OID4VCgo: a stable code, the issuer's, Authorization Server's or Verifier's own error code when it gave one (protocolError), and a message for logs: it never carries personal data, a remote party's own description, a URL's path or query, or control characters. description is a sentence fit to show the holder; isRetryable says whether trying the same step again may succeed.
