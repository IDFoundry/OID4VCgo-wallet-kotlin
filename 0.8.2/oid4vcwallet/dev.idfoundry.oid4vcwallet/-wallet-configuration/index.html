@SerialName(value = "request_refresh")
val requestRefresh: Boolean

Asks Authorization Servers for a refresh token, so Wallet.refreshCredential can later replace a credential's copies without the holder. The server must allow the wallet the offline_access scope, or the authorization fails.

requireSignedDCAPIRequests
Link copied to clipboard
@SerialName(value = "require_signed_dcapi_requests")
val requireSignedDCAPIRequests: Boolean

Refuses an unsigned OpenID4VP request over the Digital Credentials API: Wallet.startDCAPIPresentation throws untrustedVerifier, before the holder sees it. Its only identity is the origin the platform reports; HAIP requires a wallet to support unsigned requests, so set it only where every Verifier must be one verifierRoots accepts.
