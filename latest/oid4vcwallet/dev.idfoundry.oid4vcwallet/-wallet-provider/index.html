WalletProvider

interface WalletProvider(source)

The Wallet Provider's backend, which attests the wallet and its keys (HAIP 1.0 §4.4.1, §4.5.1). Keys are public JWKs, as JSON; the results are compact JWTs. A real one attests only after checking platform evidence that it's talking to the genuine app and that the keys are in secure hardware: it gives a challenge for each key the wallet makes (attestationChallenge), and checks each key's Android Key Attestation chain against it (KeyEvidence.certificateChain) before attesting.

Implement walletAttestation and keyAttestation either with the evidence (WalletAttestationRequest, KeyAttestationRequest) — which the wallet calls — or with the keys alone, which the evidence versions call by default.

open suspend fun attestationChallenge(purpose: KeyPurpose): ByteArray?

A challenge for the key attestation of the next key the wallet makes for purpose — fresh, from the Wallet Provider's backend, which remembers it — or null for none. The wallet gives it to KeyStore.createKey, so AndroidKeystoreKeyStore has Android Keystore attest the key over it (setAttestationChallenge), and the key's chain then reaches walletAttestation or keyAttestation in its KeyEvidence. Return one for KeyPurpose.HOLDER (Key Attestation) and KeyPurpose.INSTANCE (Wallet Attestation); KeyPurpose.DPOP keys aren't attested to anyone. At most 128 bytes. Called on Go's thread, which waits, once per key: a batch asks once per copy. An IOException is reported as a network failure, as the attestations' are. The default gives none, and keys carry no attestation chain.
