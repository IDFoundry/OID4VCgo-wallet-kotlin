InstanceRegistry

interface InstanceRegistry(source)

Where HttpWalletProvider keeps the wallet's registration, so the installation registers once, across launches. An instance ID isn't a secret — every request naming it is signed with the registration key — but losing it loses the instance: the wallet then registers again, with a new registration key, and the instance keys the lost instance recorded can't be attested again. FileInstanceRegistry keeps it in a file; InMemoryInstanceRegistry is for tests. Over either, every HttpWalletProvider in the process registering for the same registration takes turns; over a registry of another type, a provider takes turns only with itself: keep one provider for it.

Called on Go's thread, never the main one; an exception it throws fails the attestation as WalletException.Code.platform.
