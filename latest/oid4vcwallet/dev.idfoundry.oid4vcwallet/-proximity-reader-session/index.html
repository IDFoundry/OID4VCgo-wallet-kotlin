checkStatus

suspend fun checkStatus(): MdocStatus

Checks the revocation status of the mdoc the session verified: fetches the Token Status List its MSO names, over https from a public address, and verifies it's signed under the certificate the MSO names or else under the CA that signed the document signer (ISO/IEC 18013-5 §12.3.6). Rely on the document only when this is MdocStatus.Valid or MdocStatus.NoStatus. Call it once the session is State.Verified; before, it throws a WalletException with code wrong_step. A failed fetch is network, a list that doesn't verify protocol; cancelling the coroutine cancels it. The list covers many documents, so fetching it doesn't tell its publisher which one was presented.
