development
Link copied to clipboard
@SerialName(value = "development")
val development: Boolean

Relaxes what production requires, for a reader trying out a development issuer's documents. Never ship an app with it set. Without it, ProximityReader requires a production reader's decisions, throwing invalid_input otherwise: each role in revocation or noRevocationCheck, and anyIssuerForAnyType with issuerRoots. With it, a role in neither checks no revocation, and any IACA in issuerRoots may issue any document type. Refused (invalid_input) unless the app called OID4VC.allowDevelopment.

statusCheck
Link copied to clipboard
@SerialName(value = "status")
val statusCheck: ProximityReaderConfiguration.StatusCheck?

Whether a session checks a verified document's revocation status before reporting it. Outside development, it's required: null throws invalid_input. With StatusCheck.CHECK, a session reports ProximityReaderSession.State.Verified only for a document whose status is valid, or that has none (VerifiedMdoc.status), and fails with document_not_valid otherwise; with StatusCheck.DECLINE, nothing checks it, for a reader where something else stands in. In development, null is StatusCheck.DECLINE.
