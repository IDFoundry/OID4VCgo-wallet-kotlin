Wallet

class Wallet(configuration: WalletConfiguration, keyStore: KeyStore, credentialStore: CredentialStore, provider: WalletProvider?)(source)

A holder's wallet: OID4VCgo's walletflow over the app's key store, credential store and Wallet Provider. Creating it makes no network calls; provider is needed to receive credentials, not to present them.

Parses an OpenID4VP request delivered through the Digital Credentials API (OpenID4VP 1.0 Appendix A), as Credential Manager hands it over: protocol (openid4vp-v1-unsigned, -signed or -multisigned), its requestData (the request's data object, as JSON) and the calling page's or app's origin.
