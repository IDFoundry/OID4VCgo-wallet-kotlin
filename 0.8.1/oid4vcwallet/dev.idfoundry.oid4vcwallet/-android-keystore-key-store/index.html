AndroidKeystoreKeyStore

class AndroidKeystoreKeyStore(val options: AndroidKeystoreKeyStore.Options = Options(), authenticator: HolderAuthenticator? = null) : KeyStore(source)

The wallet's keys, in Android Keystore: P-256 keys whose private halves never leave its secure hardware — StrongBox where the device has it (Options.strongBox), else the TEE. Each key's ID is its Keystore alias after Options.aliasPrefix. Keys are usable only while the device is unlocked, and holder keys, if Options.holderUserAuthentication, each time they sign only after authenticator has authenticated the holder.
