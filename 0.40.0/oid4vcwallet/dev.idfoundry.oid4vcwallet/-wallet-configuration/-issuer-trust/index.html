acceptMDLSignerWithoutEKU
Link copied to clipboard
val acceptMDLSignerWithoutEKU: Boolean

Also accepts a document signer certificate with no extended key usage, which is refused by default for lacking the mDL document signer's (1.0.18013.5.1.2), for issuers whose document signers have none. Any certificate without one under the same IACAs, such as a revocation list signer's, can then sign mdocs the wallet accepts. It can't be set with mdocRequireEKU, or with requireEKU unless mdocRoots is set.

allowForeignIss
Link copied to clipboard
val allowForeignIss: Boolean

Receives an SD-JWT VC whose iss isn't the credential_issuer it was requested from, which is otherwise refused so an issuer can't hand over another's credential as its own. Set it only for issuers that name themselves differently, where roots certify them alone.

mdocRequireEKU
Link copied to clipboard
val mdocRequireEKU: String

A dotted object identifier: recognizes only document signer certificates with that extended key usage (the mDL's is 1.0.18013.5.1.2), in place of requireEKU, so a wallet receiving both formats can require each its own.

mdocRoots
Link copied to clipboard
val mdocRoots: String

PEM certificates: the IACAs a received mdoc must chain to, in place of roots, so a roots anchor alone, an SD-JWT VC issuer's CA say, can't sign an mDL. Empty: mdocs chain to roots.

mdocRootsByDocType
Link copied to clipboard
val mdocRootsByDocType: Map<String, String>

Each document type's own IACAs, as PEM certificates: an mdoc of a type named here must chain to them, not to mdocRoots or roots. A type named with an empty string is refused.

requireEKU
Link copied to clipboard
val requireEKU: String

A dotted object identifier: recognizes only issuer certificates under roots with that extended key usage. Outside WalletConfiguration.development, required when roots may share a trust anchor with another role's roots.

requireIssuerName
Link copied to clipboard
val requireIssuerName: Boolean

Refuses a received SD-JWT VC whose iss its signing certificate doesn't name. SD-JWT VC doesn't require them to correspond: set it where roots certify several issuers.

roots
Link copied to clipboard
val roots: String

PEM certificates: the trust anchors for issuers' credentials. A credential signed by a certificate that doesn't chain to them is refused.

statusIssuers
Link copied to clipboard
val statusIssuers: Map<String, List<String>>

The Status Issuers that may sign a credential issuer's status lists on its behalf: credential issuer (an SD-JWT VC's iss) → Status Issuer identifiers, each recognized by a certificate under roots naming it. Without it, Wallet.checkStatus accepts only a status list the issuer signed itself.
